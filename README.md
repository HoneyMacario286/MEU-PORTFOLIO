## 1. Sobre o projeto

Este é o meu portfólio pessoal, criado como trabalho prático da disciplina de Programação e Design Web.

O site apresenta algumas informações sobre mim, a minha formação, os projetos em que já trabalhei, os meus hobbies e os meus contactos.

Para fazer o trabalho usei HTML5 e CSS3, sem utilizar frameworks ou JavaScript.

## 2. Como visualizar o site

Para visualizar o site, basta abrir o ficheiro `index.html` num navegador, como Google Chrome, Microsoft Edge ou Mozilla Firefox.

Também é possível navegar pelas outras páginas através do menu que aparece no topo do site.

## 3. Páginas do site

É a página inicial do portfólio. Nela faço uma breve apresentação pessoal, apresento o meu curso e algumas áreas que me interessam.

## 4. Tecnologias utilizadas

### HTML5

Usei HTML5 para criar a estrutura das páginas.

Algumas das principais tags utilizadas foram:

* `<header>` — representa o cabeçalho do site.
* `<nav>` — contém o menu de navegação.
* `<main>` — representa o conteúdo principal da página.
* `<section>` — organiza o conteúdo em diferentes secções.
* `<article>` — utilizado para conteúdos independentes, como os cartões dos projetos.
* `<aside>` — utilizado para informações complementares.
* `<footer>` — representa o rodapé.
* `<h1>`, `<h2>` e `<h3>` — utilizados para organizar os títulos.
* `<p>` — utilizado para textos e descrições.
* `<ul>` e `<ol>` — utilizados para listas.
* `<table>`, `<thead>` e `<tbody>` — utilizados para apresentar o percurso académico.
* `<form>` — utilizado para criar o formulário de contacto.
* `<fieldset>` e `<legend>` — utilizados para organizar os campos do formulário.
* `<input>` — utilizado para diferentes tipos de entrada de dados.
* `<select>` e `<option>` — utilizados para criar uma lista de opções.
* `<textarea>` — utilizado para escrever mensagens.
* `<button>` — utilizado para o botão de envio.

## 5. CSS utilizado

O CSS foi separado dos ficheiros HTML e está dentro da pasta `css`.

### Variáveis CSS

Usei variáveis dentro de `:root` para definir cores, espaçamentos e outros valores utilizados várias vezes no site.

### Flexbox

Usei Flexbox principalmente na página dos hobbies e também no cabeçalho para organizar os elementos.

Foram utilizados recursos como:

* `display: flex`;
* `flex-direction`;
* `flex-wrap`;
* `justify-content`;
* `align-items`.

### CSS Grid

Usei CSS Grid na página de projetos para organizar os cartões dos projetos em colunas.

Também utilizei `repeat()`, `minmax()` e `auto-fit` para permitir que os cartões se adaptem ao tamanho do ecrã.

### Media Queries

Usei Media Queries para adaptar o site a diferentes tamanhos de ecrã, principalmente computador, tablet e telemóvel.

### Pseudo-classes

Foram utilizadas pseudo-classes como:

* `:hover` — para criar efeitos quando o rato passa sobre determinados elementos;
* `:focus` — para destacar campos do formulário quando estão selecionados;
* `:first-child` — para aplicar estilos ao primeiro elemento;
* `:last-child` — para aplicar estilos ao último elemento;
* `:nth-child()` — para selecionar elementos de acordo com a sua posição.

### Pseudo-elementos

Usei `::before` e `::after` para criar pequenos elementos decorativos sem precisar adicionar mais elementos HTML.

### Outros recursos

Também utilizei:

* `box-shadow` para criar sombras;
* `linear-gradient()` para criar gradientes;
* `transition` para deixar alguns efeitos mais suaves;
* `@keyframes` para criar uma pequena animação;
* `position: sticky` no cabeçalho;
* unidades relativas como `%`, `rem` e `vw`;
* seletores de atributos, como `input[type="email"]`.

## 6. Formulário

O formulário da página de contacto foi feito apenas com HTML5.

Foram utilizados diferentes tipos de campos, incluindo:

* texto;
* email;
* telefone;
* data;
* número;
* ficheiro;
* seleção;
* radio;
* checkbox;
* área de texto.

Também utilizei atributos como `required`, `pattern`, `min`, `max`, `minlength` e `maxlength` para fazer a validação dos dados sem JavaScript.
