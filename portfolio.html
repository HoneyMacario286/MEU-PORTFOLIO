Meus Projetos

Programa de Gestão Financeira Pessoal

Este projeto foi desenvolvido com o objetivo de ajudar na organização e controlo das finanças pessoais.

O programa permite registar receitas e despesas, acompanhar os gastos e obter informações sobre a situação financeira do utilizador.

Foi desenvolvido utilizando conhecimentos de programação em C++.

Controle de Rotas de Chapas

Este projeto consiste num sistema para auxiliar na gestão de chapas, motoristas e viagens.

O sistema permite gerir motoristas, gerir chapas, registar viagens e consultar relatórios.

O projeto foi desenvolvido em C++ como parte da minha aprendizagem na área de programação.

O que aprendi com estes projetos?

Durante o desenvolvimento destes projetos pude melhorar os meus conhecimentos de programação, organização de dados, criação de menus e resolução de problemas através da informática.

Estes trabalhos também ajudaram a desenvolver a minha capacidade de transformar problemas do dia a dia em possíveis soluções através da tecnologia.
